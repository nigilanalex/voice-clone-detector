Privacy policy

VoiceGuard processes audio only to produce the requested synthetic-voice screening result.

Audio handling

  • Uploaded audio is held temporarily in server memory while it is decoded and analyzed.
  • Live audio is processed in rolling windows and is not intentionally retained by the application.
  • The current application does not create user accounts or an audio archive.

Result metadata

Recent scan history is stored only in your browser and contains filenames, timestamps, file fingerprints, and results—not audio. You can clear it from the main screen.

Operational data

The hosting provider may process standard connection information such as IP addresses, request times, and error logs for security and reliability. Review the hosting provider’s policy before operating a public deployment.

Your choices

Do not submit audio without permission. You can close the page, clear browser history from the application, and avoid downloading a report.

The operator of each public deployment is responsible for publishing its identity, contact method, jurisdiction, hosting logs, and final retention terms.
